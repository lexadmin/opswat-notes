# ICAP 反向代理整合導讀

**MetaDefender ICAP Server** 讓你把檔案安全檢測「插」進現有的網路流量裡，不用改動應用系統本身。

## 一句話理解

ICAP 是一種標準協定，作用像在你的網路關卡旁邊加一個**檢查哨**：流量經過反向代理、負載平衡器或 WAF 時，順手把檔案丟給 MetaDefender 掃一下，乾淨才放行。

## 適合的場景

- 使用者透過網頁上傳 / 下載檔案，想在**不改程式**的前提下加上安全掃描。
- 已經有 F5、Fortinet、Squid 等支援 ICAP 的設備，想直接串接。
