# MetaDefender Core 中文導讀

這篇用白話帶你理解 **MetaDefender Core** 是什麼、解決什麼問題，適合第一次接觸的同仁或客戶先看。

## 一句話理解

MetaDefender Core 是一個**檔案安全檢測引擎**：任何要進入你組織的檔案，先送進來「安檢」，確認乾淨、無害、合規之後才放行。

你可以把它想像成機場的**行李安檢站** —— 不是只靠一台機器，而是同時用很多種方式檢查同一件行李，任何一種發現問題都會攔下來。

## 三大核心能力

| 能力 | 白話說明 | 對應威脅 |
|------|----------|----------|
| **Multiscanning** | 同時用多套防毒引擎掃描同一個檔案 | 已知病毒、惡意程式 |
| **Deep CDR** | 把檔案拆解重組，移除可能藏毒的元件 | 未知威脅、零時差攻擊 |
| **Sandbox** | 在隔離環境實際「引爆」檔案觀察行為 | 進階規避型惡意程式 |

!!! tip "為什麼要用多套引擎？"
    沒有任何一套防毒引擎能抓到所有病毒。多套引擎一起掃，等於多雙眼睛同時看，抓到率大幅提升 —— 這正是 Multiscanning 的核心價值。

## 典型使用場景

- **上傳檔案掃描**：網站、應用系統收到使用者上傳的檔案，先過一次 Core 再儲存。
- **供應鏈安全**：外部廠商交付的檔案、程式碼，進場前先檢測。
- **可攜式媒體管控**：搭配 Kiosk，USB 隨身碟插入前強制安檢。
